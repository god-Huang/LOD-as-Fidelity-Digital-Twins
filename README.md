# LOD-as-Fidelity Digital Twins: Reduced-Order Encoding, Conservation-Preserving Surrogates and the Boundary Between Inference and Measurement

Code, derived data and result tables for the study of the same title. Every number the paper
reports is produced by the scripts here from the data here.

## Quick start

```bash
pip install -r requirements.txt
cd experiments && bash run_all.sh
```

The driver runs the 26 measurement stages in dependency order. Each stage reads the artefacts of
the stages before it and writes its own result tables under `experiments/results/`, so a completed
run regenerates every measured quantity in the study from the inputs in this archive. Five further
stages exist in the project - figure generation, exhibit numbering, the two text audits and the
Chinese-manuscript sync - and are deliberately not part of this data archive.

## Contents

| path | what it holds |
|---|---|
| `experiments/src/` | the numbered pipeline stages and the support modules they import |
| `experiments/data/derived/` | tile index, level-cut ladder, planar network, branch and station tables, the section field at every level cut |
| `experiments/results/` | every result table and report the study measures |
| `experiments/run_all.sh` | the driver |
| `STAGES.md` | the shipped stages, in run order, with what each one writes |

## Inputs

Stages 01 and 02 parse the raw 3D Tiles product; that survey is proprietary and is not included.
Everything downstream is included, so the chain from stage 03 onwards runs as-is, and an equivalent
3D Tiles product can be pushed through stages 01-02 to reproduce the whole chain. The per-face
semantic map `experiments/data/derived/station_semantics.npz` (51 MB) is regenerated by stage 07 from the committed inputs and
is therefore not versioned here.

## Runtime and hardware

Single workstation, CPU only; the machine's GPU is present but unused. Full run: about 2.5 h,
dominated by the operator-training stages (geometry-domain 497 s, physics-domain 492 s, active
re-survey 834 s) and by the repetition study. Measured per-stage times are in
`results/environment.txt` and `results/compute_cost.csv`.

## Checking a run

Every stage prints what it wrote and exits non-zero on an internal contradiction (a coverage
share that does not add up, a bootstrap interval that excludes its own point estimate, a solver
residual above its tolerance). `experiments/results/` is the record: 77 tables and reports, each
produced by the stage listed in `STAGES.md`.
